# Command Authority — Callsigns, Nets & Ranks

Unofficial fan reference site for *Command Authority: Military Roleplay* (Roblox). Static HTML/CSS/JS, no build step.

## Deploy on GitHub Pages
1. Create a new public repository and upload everything in this folder (keep `index.html` at the repo root).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
